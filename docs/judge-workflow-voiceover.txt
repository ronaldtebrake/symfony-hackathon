Why load a whole catalog of tools to answer one question? With Symfony Code Mode, an agent starts with two MCP tools. One to search, one to execute.

What if the job takes several tools? We prototyped the MCP working group’s Groups proposal to bundle tools with team instructions.

Here’s a support colleague asking what to tell a customer. From that one question, the agent finds the refund procedure and opens it.

Here’s what the team wrote. Read the order first. Then check the policy listed on that order. If either read fails, leave the review open.

Watch what comes back from the first read. The order has a field called policy ID. Its value is standard EU.

That value goes straight into the second read. A client can chain those calls in code.

Seventy-five euros is over the policy’s fifty-euro limit. The agent recommends manual review.

Now the colleague asks about a second order. The agent already knows the procedure. But can this user read that order? Symfony checks again and denies access. The agent leaves the refund undecided.
